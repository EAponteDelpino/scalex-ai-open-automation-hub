# Ecommerce Open Toolkit — English

Open `index.html` directly or deploy this folder as static assets. Select one of ten calculators, enter your own values and run calculations locally.

All numbers are examples. Money stays in the same unit; a change in currency selection is a **display setting**, not conversion. Percent inputs use values from 0–100. CPA is cost per acquisition, ROAS is revenue divided by ad spend, and break-even calculations assume constant unit economics.

See [formulas and tests](../README.md). Please contribute bug reports with reproducible sample inputs, no real customer or payment data.
