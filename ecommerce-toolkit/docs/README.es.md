# Ecommerce Open Toolkit — Español

Las diez herramientas se ejecutan directamente en el navegador sin APIs externas. Abre `index.html`, elige una calculadora, modifica los valores de ejemplo y presiona **Calcular**.

Los porcentajes se introducen de 0 a 100; escribe 3 para 3%. Introduce siempre los montos en una sola moneda. Cambiar COP/USD/EUR solo modifica su presentación: **no convierte monedas**.

ROAS representa ingresos atribuidos sobre publicidad, no rentabilidad. Los escenarios publicitarios son hipótesis. Los modelos de contraentrega y logística calculan valores esperados, no garantías.

Consulta [fórmulas, instrucciones y pruebas](../README.md). Las contribuciones con ejemplos reproducibles y datos ficticios son bienvenidas.
