# Consent, privacy and security

- Never send outreach without lawful, documented and revocable consent, and the appropriate WhatsApp-approved message template where required.
- The demonstration eligibility flags are not substitute for provider-side checks. Check real service windows, category and opt-outs before sending.
- Keep all provider credentials server-side; never commit or place in static site code.
- Observe data minimization, customer deletion requests, retention schedules, audit logs and appropriate encryption.
- Messages produced here are **drafts**, not approved templates; human verification is required.
- No scraping of numbers, unsolicited messages, spoofing, bypasses or mass messaging.
- The `wa.me` generator includes message text in a URL; avoid sensitive data in links.
