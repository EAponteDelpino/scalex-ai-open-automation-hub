# Guía en español

Incluye 10 herramientas que funcionan localmente en el navegador para **planificar** comunicaciones comerciales por WhatsApp. No envían mensajes, no contienen bots reales y no se conectan con GHL, SellerChat, Meta ni servicios de IA.

El generador wa.me abre un mensaje preparado solo si un usuario pulsa el enlace. El seguimiento y la recuperación comprueban únicamente indicadores **de demostración**: consentimiento declarado, baja y plantilla aprobada. La verificación efectiva de esos requisitos debe implementarse con registros válidos del proveedor.

Prueba con datos ficticios. Los agentes de ventas son borradores basados en reglas, no modelos de IA ejecutándose en el navegador. Ejecuta `npm test` para revisar las pruebas de lógica.
