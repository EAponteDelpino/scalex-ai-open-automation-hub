# English guide

Ten local browser tools for **designing** WhatsApp customer journeys. These are deterministic examples, not actual deployed AI models or messaging agents.

Consent, opt-out and template approval fields are demonstration flags, **not** provider verification. Real WhatsApp integration requires authenticated APIs, current policy review, user authorization and secure backend handling. No API keys, contact lists, or outbound automation are included.

Run `npm test` in the project folder to check helper logic.
