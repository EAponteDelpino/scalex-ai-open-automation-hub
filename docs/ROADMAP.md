# ScaleX AI Open Source Roadmap

This document records intended work; no milestone is a promise or evidence of completion.

## Phase 1 — Quality and release readiness
- Improve static JavaScript safety and tests
- Run the n8n import and HTTP test suite in a real n8n instance
- Test GHL blocks in a sandbox and track failures
- Publish a transparent beta release after critical defects are resolved

## Phase 2 — Practical developer tools
- Ecommerce contribution-margin and maximum-CPA calculators
- Opt-in WhatsApp conversation templates and sample validation
- Configurable AI agent evaluation examples (avoid external API keys)
- Trading risk/expectancy calculators (educational, not signals)
- Free Spanish-English AI learning labs

## Phase 3 — Contributors and community
- Maintain concise, reproducible issues with clear acceptance criteria
- Offer contributor mentorship and review substantive PRs
- Track forks, dependent projects, accepted external contributors and real usage using publicly verifiable data
- Make no claims about Claude open-source program approval until Anthropic confirms it

## Maintenance
Prioritize test quality and a useful user experience over number of commits, repositories or PRs.
