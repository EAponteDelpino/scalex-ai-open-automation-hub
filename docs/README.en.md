# English guide

ScaleX AI Open Automation Hub contains **30 n8n demonstration workflows** and **10 AI-agent role templates**.

## Setup

1. Use a compatible n8n version in a test workspace.
2. Import a JSON file from `workflows/n8n/`.
3. Send a JSON POST request to the Webhook node's test URL.
4. Inspect the Respond to Webhook result and tailor the Code node rules.
5. Add authentication, error handling, rate limits, logging controls and monitoring before production.

Workflows do not automatically integrate with WhatsApp, GoHighLevel, Shopify, Meta Ads or an AI service. Agent profiles are not deployed assistants. Use fictional sample data and require opt-in before marketing outreach.
