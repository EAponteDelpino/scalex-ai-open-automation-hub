# AI Agent Builder Toolkit — Guía en español

Diez herramientas locales de diseño de agentes, prompts, comprobación heurística, bases de conocimiento, configuración RAG, estimación de tokens y costos, comparación de textos, diagramas y exportación JSON.

Abre `index.html` en el navegador, selecciona el módulo y pulsa **Procesar**. Todas las herramientas funcionan sin credenciales ni servicios de pago.

**Limitación esencial:** no hay un agente de IA funcionando detrás del formulario. No se ejecutan modelos, flujos, APIs ni búsquedas RAG. La evaluación de prompts comprueba palabras clave, no mide precisión. El estimador de tokens usa una proporción aproximada de caracteres; los costos dependen de tarifas que el usuario introduce.

No escribas secretos ni información privada de clientes. Las entradas no se envían a servidores. Ejecuta `npm test` con Node.js 18+ para comprobar la lógica.
