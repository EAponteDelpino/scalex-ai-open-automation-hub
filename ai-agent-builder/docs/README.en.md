# AI Agent Builder Toolkit — English

Ten offline browser tools for building agent configurations, structuring prompts, lexical prompt checking, verified-source knowledge drafts, RAG parameter design, user-priced API cost projection, approximate token counting, string comparison, automation graphs, and JSON configuration export.

**They do not run AI models, perform actual RAG, integrate providers, or send data to servers.** The prompt grader is a simple keyword heuristic; token estimates are character-based and pricing is supplied by the user.

Run `npm test` in the module directory (Node.js 18+); use sample data only.
