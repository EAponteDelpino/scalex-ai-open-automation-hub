# GHL Developer Toolkit — English guide

Fifteen configurable **example components**, not an official HighLevel plugin or importable snapshot.

To install: create a test funnel, add a Custom Code/HTML element, paste the chosen `index.html` content, then include the shared styles and JavaScript helpers as supported by your page editor. Replace fake data with test-specific configuration. Verify desktop/mobile rendering and any native GHL workflow mapping in a sandbox.

**Limitations:** custom HTML does not automatically create native GHL contacts; checkout links do not verify payment; a screenshot or reference number is not provider proof. Backend authentication, fraud checks and payment verification are required before granting access. Do not ship personal data or keys in browser JavaScript.

See [component catalog](COMPONENTS.md) and [security](SECURITY.md).
