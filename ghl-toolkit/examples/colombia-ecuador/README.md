# Example: Colombia / Ecuador course enrollment

This example adapts a cross-border course registration funnel concept, using **fictional contact data** and **illustrative prices**.

1. Build GHL funnel pages for Colombia and Ecuador.
2. Add [multi-currency checkout](../../checkout/multi-currency-checkout/index.html) or distinct local plan selectors.
3. Use native GHL forms with a custom `course_plan` field. Validate real workflow mapping before rollout.
4. Add [payment instructions](../../checkout/payment-instructions/index.html).
5. Use provider HTTPS checkout links on configured hosts; redirect customers without capturing card data.
6. Verify payments in a trusted backend before marking contacts paid or issuing access.
7. Configure WhatsApp opt-in and country-aware messaging; **never assume a photo is payment confirmation**.

**Pricing samples (not live offers):** CO 99,000 COP; EC 29.90 USD. These are example values, not exchange-rate conversions.

**Do not include:** actual Bold links, customer phone numbers, payment references, private agency templates or credentials in the public repo.
